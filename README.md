# ポケット17 ミニゲーム機

ブラウザだけで遊べるミニゲーム集。サーバー側の処理は一切ないので、ファイルを置くだけで動きます。

- CPU戦・同じ端末での2人対戦・オンライン対戦（ピンポン／三目ならべ／四目ならべ）
- 名前を入れると順位がつくランキング（この端末のなかだけ）
- 放置で増える育成ゲーム「たまご牧場」
- 3周タイムアタックのレース「ハイウェイ17」とダンジョン探検「ならく潜り」
- 壁を建てて撃ち合う1対1「ブロックデュエル」（CPU戦・オンライン対戦）
- 3Dの一人称で建築しながら戦う「スカイフォート」（CPU戦・オンライン対戦）
- キーボードとタッチの両対応。スマホでは画面下の十字キーとA/Bボタンで操作
- スコアは各自のブラウザに保存されます（サーバーには何も送りません）
- 電波が切れても、一度開いたことがあれば遊べます

## 1. GitHub Pages で公開する手順

GitHubのアカウントだけあれば、無料で、広告なしで公開できます。コマンドは使いません。

1. GitHub にログインし、右上の「+」→ **New repository**
2. **Repository name** に `pocket17` と入力し、**Public** を選んで **Create repository**
3. 次の画面の **uploading an existing file** を押す
4. このフォルダの中身を**すべて**ドラッグ＆ドロップする
   （`index.html` が一番上の階層に来るようにしてください。`site` フォルダごとではなく、**中身**を入れます）
5. 下の **Commit changes** を押す
6. 上部メニューの **Settings** → 左の **Pages** を開く
7. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**
8. 1〜2分待つと、同じ画面に公開URLが出ます

```
https://<あなたのGitHub名>.github.io/pocket17/
```

このURLを配れば、誰でも、ログインなしで遊べます。

### 公開URLはもう入っています

`index.html` / `robots.txt` / `sitemap.xml` には

```
https://99pksv8hn8-netizen.github.io/pocket17/
```

が設定済みです。このURLで公開するなら、何も書きかえる必要はありません。

### 独自ドメインを使う場合

Settings → Pages → **Custom domain** にドメインを入れ、ドメイン側で `CNAME` を `<あなたのGitHub名>.github.io` に向けます。`index.html`・`robots.txt`・`sitemap.xml` の中のURLも新しいドメインに書きかえてください。

## 2. オンライン対戦について

ブラウザ同士を直接つなぐ方式（WebRTC）です。ゲームのデータは2人の端末の間を直接行き来し、どこかのサーバーに保存されることはありません。

**使いかた**

1. 対戦ゲームを開き「オンライン対戦」を選ぶ
2. 2人が**同じ合言葉**（英数字）を入れる
3. 先に入ったほうが進行役になり、もう片方が入ると自動で始まる

**知っておいてほしいこと**

- 2人が**同時に**ページを開いている必要があります。あとから見る形式ではありません
- 最初のつなぎ役として、PeerJS の無料の仲介サーバーを使っています。ここが混んでいるとつながらないことがあります。そのときは合言葉を変えてやり直してください
- 学校や会社の厳しいネットワークでは、直接つなぐ通信がブロックされて失敗することがあります。その場合は「ふたりで（同じ端末）」で遊べます
- 合言葉は暗号ではありません。同じ言葉を入れた第三者が入ってくる可能性があるので、推測されにくい言葉にしてください

## 3. ランキングについて

名前を入れて遊ぶと、ゲームごとの順位と総合順位がつきます。

- 記録は**その端末のブラウザのなか**にだけ残ります。サーバーには送っていません
- つまり、同じ端末で名前を切り替えて遊べば順位を競えます。別々の端末どうしでは競えません
- 総合得点は、各ゲームの順位で決まります（1位=10点、2位=6点、3位=4点、それ以下=1点）
- 点数に応じてブロンズ→シルバー→ゴールド→プラチナとランクが上がります
- ふさわしくない名前が入力された場合、ランキング画面の各行の「✕」で個別に消せます。「記録をぜんぶ消す」もあります

あとで全員で競う全国ランキングにしたい場合は、`rank.js` の `read()` と `write()` を外部サービスの読み書きに差し替えれば、他のコードは変えずに動きます。

## 4. 更新のしかた

ファイルを差し替えたら、**`sw.js` の先頭にある `pocket17-v5` の数字を1つ上げてください**（`v6`、`v7`…）。

この数字が変わらないと、一度開いたことがある人の端末に古いファイルが残り続けます。

## 5. ファイルの構成

```
index.html              入口。JSを読み込む順番もここに書いてある
404.html                ページが見つからないとき
style.css               筐体と画面の見た目

core.js                 パレット・入力・描画・音・演出
net.js                  通信（WebRTC と claude.ai の room の切り替え）
app.js                  カタログ・起動と終了・スコア
games-a.js              01-05
games-b.js              06-12
games-c.js              13-14
games-d.js              18（育成放置）
games-e.js              19-20（レース・冒険）
games-f.js              21（建築バトル）
games-g.js              22（3D建築バトル）
games-vs.js             15-17（対戦）
rank.js                 名前とランキング
boot.js                 電源投入

manifest.webmanifest    ホーム画面に追加したときの設定
sw.js                   オフライン対応（更新時は中の v1 を上げる）
robots.txt / sitemap.xml 検索サイト向け
favicon.svg ほか         アイコンとSNS用の画像
.nojekyll               GitHub Pages 用のおまじない
```

JavaScriptは `index.html` に書かれた順番で読み込まれます。ゲームを足すときは `GAMES.push({...})` を使い、`boot.js` より前に読み込んでください。

## 6. 外から読み込んでいるもの

| 何を | どこから | なくなったらどうなるか |
|---|---|---|
| 画面の書体（DotGothic16 / Zen Kaku Gothic New） | Google Fonts | 端末の標準の書体で表示されます。遊ぶのに支障はありません |
| 通信の部品（PeerJS 1.5.5） | jsDelivr | オンライン対戦だけが使えなくなります。他の遊びかたは影響を受けません |
| 3Dの部品（three.js 0.149.0） | jsDelivr | 「スカイフォート」だけが遊べなくなります。他の21本は影響を受けません |

いずれも、読み込めなくても他のゲームは動くように作ってあります。

なお「スカイフォート」は3Dの部品を外から読み込むため、**この1本だけはオフラインでは遊べません**。他の21本は一度開いていればオフラインでも動きます。

## 7. 動作環境

Chrome・Safari・Firefox・Edge の最近のもの。スマートフォンでも遊べます。

ゲームの中身はすべてこのために書いたオリジナルの実装です。
